# 腾讯云轻量服务器自动抢购脚本 (Playwright版)

这是一个基于 Python 和 Playwright 的自动化脚本，专为抢购腾讯云活动页面的轻量应用服务器（如 38元/年 4核4G 套餐）而设计。

## ✨ 功能特点

*   **全自动流程**：自动登录检测、商品定位、倒计时等待、毫秒级抢购、自动下单。
*   **精准定位**：采用双轮筛选机制（价格匹配+特征匹配）和容器定位策略，精准锁定目标商品，排除干扰。
*   **防风控机制**：
    *   赛前自动刷新保活（防止登录态过期）。
    *   模拟真实用户滚动和点击行为。
*   **高鲁棒性**：
    *   支持多种按钮状态识别（立即抢购、取消提醒、已设置等）。
    *   自动处理登录弹窗。
    *   失败自动重试与兜底策略。
*   **多模式支持**：支持测试模式（79元）和生产模式（38/39元）。

## 🛠️ 环境要求

*   Python 3.8+
*   Playwright

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
playwright install
```

### 2. 检查配置

打开 `config.py` 文件，确认以下配置符合你的需求：

```python
# 运行模式
RUN_MODE = {
    "test_mode": False,           # False = 正式抢购模式 (38元)
    "buy_times": ["10:00:00", "15:00:00"],  # 抢购时间点
}

# 目标商品
TARGET_CONFIG = {
    "text": "4核4G",
    "prod_prices": ["38", "39"],  # 目标价格
}
```

### 3. 运行脚本

建议在抢购开始前 15-30 分钟运行脚本：

```bash
python main.py
```

### 4. 操作流程

1.  **启动**：脚本会自动打开浏览器并访问活动页面。
2.  **登录**：如果检测到未登录，脚本会暂停并提示扫码。请在浏览器中扫码登录。
3.  **定位**：登录成功后，脚本会自动滚动页面寻找目标商品，并高亮显示。
4.  **等待**：脚本会进入倒计时状态，每 0.5 秒检查一次时间。
5.  **抢购**：
    *   **赛前刷新**：抢购前 2 分钟（如 09:58），脚本会自动刷新页面以保持登录态。
    *   **准点出击**：时间一到（0秒误差），脚本会自动点击购买、处理弹窗、选择镜像并提交订单。
6.  **支付**：脚本将停留在支付页面，请手动完成最后支付。

## 📂 项目结构

*   `main.py`: 主程序入口，负责调度整个流程。
*   `config.py`: 配置文件，包含商品信息、运行模式和超时设置。
*   `product_finder.py`: 核心模块，负责在复杂的页面中精准查找和定位商品。
*   `purchase_flow.py`: 购买流程模块，处理下单、弹窗和协议勾选。
*   `login_handler.py`: 负责检测登录状态和处理登录弹窗。
*   `logger.py`: 日志模块，支持控制台输出和文件记录。
*   `utils.py`: 通用工具函数。
*   `logs/`: 存放运行日志（自动生成）。

## ⚠️ 注意事项

1.  **系统时间**：请确保你的电脑系统时间是准确的，脚本依赖本地时间触发抢购。
2.  **人工值守**：虽然脚本是自动的，但建议在抢购关键时刻（如 09:58 - 10:01）保持人工关注，以防出现滑块验证码等需要人工介入的情况。
3.  **浏览器窗口**：运行过程中请勿关闭浏览器窗口。

## 📝 常见问题

*   **Q: 为什么抢购前浏览器突然刷新了？**
    *   A: 这是正常的保活机制，为了防止登录态过期导致抢购失败。
*   **Q: 脚本一直显示“未找到目标商品”怎么办？**
    *   A: 请检查 `config.py` 中的 `TARGET_CONFIG` 是否与当前活动页面的商品描述一致。脚本会自动重试查找。
